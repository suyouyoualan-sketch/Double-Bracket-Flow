# Double-Bracket-Flow

This is a project about the **double bracket flow** based on R. W. Brockett's work *Dynamical systems that sort lists, diagonalize matrices, and solve linear programming problems*.
It is a course project for *PH3409/MH3702 Geometric Methods in Mathematical Physics* by Prof. Francois Gay-Balmaz.

The written report and slides are uploaded in this repository.
